# Audio DSP SFX

Обработка аудио и игрового звука: нормализация громкости (LUFS / True Peak), устранение клиппинга и щелчков, Web Audio / FFmpeg фильтры и оптимальные форматы.

## Когда применять
- Подготовка озвучки, звуковых эффектов (SFX), подкастов, TTS и интерактивного Web Audio
- Исправление щелчков на склейках, перегруза, разной громкости треков и задержек старта

## Рабочий протокол
1. Измеряй громкость по стандарту EBU R128 (`loudnorm` в FFmpeg: `-14 LUFS` веб/видео, `-16 LUFS` подкасты, True Peak <= `-1.0 dBTP`) вместо наивной пиковой нормализации.
2. Убирай щелчки на границах клипов короткими fade-in / fade-out (5–15ms) или разрезом в точке перехода через ноль (zero-crossing).
3. Выбирай правильный формат: `OGG Opus` / `AAC` для веба и игр, `WAV` (PCM 16/24-bit 48kHz) для мастер-исходников и монтажа.
4. В Web Audio API используй `AudioContext` с разблокировкой по жесту пользователя, меняй gain через `linearRampToValueAtTime` (не резким присваиванием `.value = 0`, дающим щелчок!) и ограничивай полифонию SFX.
5. Проверяй итоговый трек на отсутствие цифрового клиппинга (`0 dBFS`) и соответствие частоты дискретизации (`48000 Hz`).

## Чеклист качества
- [ ] True Peak не превышает `-1.0 dBTP`, отсутствует слышимый клиппинг и щелчки на старте/стопе
- [ ] Все звуковые ассеты приведены к единому целевому уровню громкости
- [ ] Для коротких UI/игровых SFX добавлен минимальный разброс pitch (±3–5%) против «эффекта пулемёта»

## Антипаттерны (чего избегать)
- Загружать 10-мегабайтные несжатые WAV-файлы фоновой музыки в веб-приложение
- Резко обрывать `GainNode` с 1.0 до 0.0 за 0 миллисекунд

## Верификация перед завершением
Прогони `ffmpeg -i out -af ebur128=peak=true -f null -` и проверь LUFS + True Peak.
