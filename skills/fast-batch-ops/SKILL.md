# Fast Batch Operations & Token Efficiency

Используй этот скилл для максимизации скорости выполнения задач и экономии контекстного окна.

## 1. Пакетная диагностика (1 вызов вместо 10)
- Если нужно проверить 10–30 файлов конфигураций, распаковать `plugin.yml` из нескольких `.jar` или сверить права в базе данных — **не вызывай `read_file` или `run_command` 20 раз подряд**.
- Напиши один компактный `python3 -c '...'` скрипт, который за 1 секунду соберёт нужную выжимку из всех файлов сразу.

## 2. Точечное чтение и редактирование
- Для больших логов (`latest.log`, `transcript.jsonl`) сначала находи нужные строки через `grep -n` или `tail -n`, а затем читай только целевой диапазон (`StartLine` / `EndLine`).
- При массовом переводе или обновлении нескольких YAML-конфигов проверяй валидность всех изменённых файлов одним прогоном `yaml.safe_load`.

## 3. Золотое правило: «Есть бэкап — нет факапа»
- Перед перезаписью важных `.jar`, баз данных или массовым удалением всегда сохраняй резервную копию в локальную папку `backups/` текущего проекта (исключённую из Git) или в `~/.local/share/agy-backups/`.
