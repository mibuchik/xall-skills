# Ffmpeg Media Pipelines

Надёжные медиа-пайплайны на FFmpeg/FFprobe: инспекция потоков, корректные кодеки и пиксельные форматы (`yuv420p`), `-movflags +faststart`, фильтры и пакетная обработка.

## Когда применять
- Конвертация, обрезка, склейка, сжатие видео/аудио, извлечение кадров и субтитров через FFmpeg
- Исправление невоспроизводимых MP4 в браузерах/Telegram и рассинхронизации аудио

## Рабочий протокол
1. Всегда сначала инспектируй входной файл через `ffprobe -v error -show_format -show_streams -of json <file>`.
2. Для максимальной совместимости MP4 (браузеры, телефоны, Telegram, Discord) задавай `-c:v libx264 -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 192k`.
3. Если перекодирование не требуется (обрезка по ключевым кадрам, смена контейнера, удаление аудио `-an`), используй `-c copy` — мгновенно и без потери качества.
4. При масштабировании следи за чётными размерами (`scale=1280:-2`), иначе `libx264` + `yuv420p` упадёт на нечётной высоте!
5. Проверяй результат через `ffprobe` (длительность, кодеки, fps, битрейт, наличие аудио) и не перезаписывай исходник тем же именем.

## Чеклист качества
- [ ] Чётные размеры кадра (`-2`) и совместимый `yuv420p` для H.264
- [ ] Флаг `-movflags +faststart` выставлен для мгновенного старта в вебе
- [ ] Исходный файл сохранён нетронутым, выход проверен `ffprobe`

## Антипаттерны (чего избегать)
- Указывать `-i file.mp4 ... file.mp4` (FFmpeg немедленно уничтожит входной файл!)
- Забывать `-pix_fmt yuv420p`, получая `yuv444p`, который показывает чёрный экран в Safari/мобильных

## Верификация перед завершением
Проверь итоговый файл через `ffprobe` и извлеки 1–2 проверочных кадра при сложной фильтрации.
